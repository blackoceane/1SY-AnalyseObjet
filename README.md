# Analyse orientée objet

## Description

Ce dépôt contient les travaux réalisés dans le cadre du cours d’**analyse orientée objet**.

L’objectif du cours est d’apprendre à analyser les besoins d’un système avant sa programmation. Les travaux utilisent principalement UML afin de représenter les acteurs, les fonctionnalités, les scénarios d’interaction et les changements d’état d’un système.

## Concepts étudiés

Dans ce cours, nous étudions notamment :

- Les diagrammes de cas d’utilisation
- Les diagrammes d’états
- Les diagrammes de séquence
- L’identification des acteurs et des besoins du système
- La modélisation des interactions entre les objets
- L’analyse des scénarios d’utilisation

## Diagramme de cas d’utilisation

Le diagramme de cas d’utilisation permet de représenter les fonctionnalités offertes par un système selon le point de vue des utilisateurs.

Il aide à identifier :

- Les acteurs qui interagissent avec le système
- Les actions que les acteurs peuvent effectuer
- Les relations entre les cas d’utilisation
- Les besoins fonctionnels du système
